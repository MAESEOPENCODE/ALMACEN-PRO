SALSA LOG · OPERACIONES — SUBIDA A GITHUB PAGES

1. Extrae todos los archivos de este ZIP en la raíz del repositorio que publica GitHub Pages (por ejemplo, maeseopencode/ALMACEN-PRO). No subas solo index.html: conserva juntos index.html, assets/, manifest.webmanifest, sw.js y todos los iconos.
2. Publica el repositorio desde la carpeta raíz. El build usa rutas relativas y admite la URL con subruta /ALMACEN-PRO/.
3. Para instalar, abre en Chrome la dirección pública HTTPS, no una dirección local 127.0.0.1 ni una vista previa temporal. En móviles, toca ⋮ → Instalar aplicación o Añadir a pantalla de inicio. En ordenador, elige ⋮ → Enviar, guardar y compartir → Instalar página como aplicación. En iPhone/iPad, abre la web con Safari y elige Compartir → Añadir a pantalla de inicio.
4. Chrome puede no mostrar el botón automático en todos los dispositivos. SalsaLog ofrece instrucciones manuales en pantalla; si aparece «Instalar app», úsalo. La instalación exige conexión segura HTTPS y los archivos de manifest, iconos y service worker publicados juntos.
5. Al abrir SalsaLog con conexión, el service worker comprueba la versión y descarga los últimos archivos. Al activarse un build nuevo, reemplaza la caché anterior y recarga la aplicación. Si acabas de subir el ZIP, cierra la app instalada y vuelve a abrir la URL HTTPS cuando GitHub Pages termine de publicar.
6. Los datos quedan en el almacenamiento local de ese navegador/dispositivo, no se sincronizan. Descarga periódicamente una copia JSON con «Guardar copia en el móvil» y restáurala cuando cambies de dispositivo.

Los valores de formato, contenido por unidad y unidades por caja se pueden ajustar por línea al confeccionar el palet; quedan reflejados en la etiqueta, ficha y packing list.
